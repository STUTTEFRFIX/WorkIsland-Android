## 1. 目标

1.5 之前的设置页是一整页长列表：状态、340dp bot 舞台、开关、滑块、说明、测试按钮全堆在一起，
首屏控件多、层级不清。这次重排的目标只有两个：

1. **首屏只回答一个问题**：现在是什么状态、胶囊长什么样、怎么开始测试。
2. **设置项按用途分组**：显示方式、胶囊样式、外观、保活、高级与测试；高级/测试默认收起。

视觉上遵循 MD3 深色 + 陶土主色，但只保留一套圆角、一套间距、一个 primary。

---

## 2. 信息架构

| 页面 | 内容 |
|---|---|
| **状态** | 胶囊预览、通知 / 实时更新 / 电池状态、显示方式摘要、「开始一个测试任务」 |
| **设置** | 显示方式、胶囊样式、外观、保活、高级与测试、页脚 |

- 顶部是 26sp 标题 + 14sp 副标题 + 版本 pill，下面是 56dp 的「状态 / 设置」分段标签。
- 状态页不放开关键设置；设置页不重复状态页的大预览。
- 「高级与测试」默认折叠：状态 look 预览、更新 / 完成 / 清除通知。
- 页脚只写版本、许可和图标归属，不再堆长段说明。

## 3. 设计令牌

| 类别 | 值 |
|---|---|
| 背景 | `#121110` |
| 卡片 | `#1C1A18`，1dp `#2A2625` 描边 |
| 次级面 | `#26231F`（分段控件、spinner 胶囊） |
| 主色 | 陶土 `#D97757`，on-primary `#1A0F0B` |
| 主色软底 | `#3A2A22`（选中 tab / 分段） |
| 文字 | `#F3EFE9`；弱化 `#B6AEA3`；说明 `#8A837A` |
| 状态色 | 成功 `#78C58A`、错误 `#E5484D`、警告 `#E6A23C`，只用于小圆点/数值 |
| 卡片圆角 | 12dp |
| 按钮 / tab / 分段 | 胶囊（高度一半）；对话框 28dp |
| 间距 | 4 / 8 / 12 / 16 / 24；卡片内 16dp，卡片间 16dp |
| 触控 | ≥48dp；行高 48dp；tab 48dp；分段 48dp |
| 字号 | 标题 26sp / 卡片标题 16sp / 行标题 15sp / 标签 14sp / 说明 12–13sp |
| 行高 | CJK 1.4–1.6 |
| 动效 | 只动 transform / opacity；UI <300ms；按压 120ms；高频开关/滑块不加入场动画 |

**禁用**：纯黑 `#000000`、纯白 `#FFFFFF`、紫蓝渐变、霓虹辉光、堆叠玻璃、漂浮 blob、
假 dashboard、三列假 KPI、三等分卡片、嵌套卡片、emoji、渐变文字、产品界面 eyebrow。

## 4. 组件模式

| 组件 | 规则 |
|---|---|
| `card()` | 卡片标题 16sp + 13sp 摘要；内容行直接放卡片，不再套一层卡 |
| `switchRow()` | 左标题/摘要、右 Switch；Switch 用陶土 thumb + 深棕 track |
| `valueRow()` | 左标题/摘要、右值 + `›`；整行可点，48dp |
| `divider()` | 1dp `#2A2625`，只在行之间 |
| `animSegmented()` | 3 段（关闭 / 标准 / 流畅），选中用主色软底，48dp |
| `spinnerRow()` | 48dp 胶囊底 + Spinner + `▾`；Spinner 自己也可点 |
| `addCapsuleSlider()` | 标题左、值右，下面 48dp SeekBar；陶土进度条 |
| `primaryButton()` | 陶土实底、深色字、胶囊、48dp；每屏最多一个 |
| `tonalButton()` | 次级面、描边、白字；用于测试/设置动作 |
| `textButton()` | 主色文字，48dp；用于「恢复默认」 |
| `CapsuleView` | 悬浮窗和设置页预览共用；字号/高度/位置/透明度由 `CapsuleStyle` 控制 |

**预览**：状态页和胶囊样式卡各有一个 `CapsuleView`，都走 `updatePreview()`；
预览的 mock 屏幕用暖灰渐变（`#2A2622 → #151311`），不是紫蓝渐变。

**状态栏安全区**：targetSdk 36 强制 edge-to-edge，`setDecorFitsSystemWindows` 不能依赖；
`applyWindowInsets()` 给根视图加 `systemBars() | displayCutout()` 的 padding。

## 5. 这次去掉了什么

- 340dp bot 舞台 → 128dp 外观预览；look 切换移入折叠的「高级与测试」。
- 6 个测试按钮 → 状态页只留「开始一个测试任务」，其余收进折叠区。
- 长段说明 → 一行说明 + 卡片摘要。
- 重复的「显示方式」文字 → 状态页一行摘要 + 设置页开关。
- 单独的动画 Spinner / 模式 Spinner → 3 段分段控件 + 两个独立 Switch。
- 居中的大标题/长备注 → 左对齐标题、卡片层级。

## 6. 维护约定

1. 新控件先决定它属于「状态」还是「设置」，再放进对应卡片；不要往首屏继续堆。
2. 不嵌套卡片，不做三等分卡片，不用 emoji 当图标。
3. 一个页面只保留一个 primary 实底按钮；其他动作用 tonal / text。
4. 所有可点元素 ≥48dp；所有说明文字 ≥12sp；CJK 行高 ≥1.4。
5. 新增颜色、圆角、间距前先查第 3 节；改令牌时同步更新本文件、`screenshots/14-ui-settings.png` 和 `workisland-ui` skill。
6. 设计总纲 / MD3 规范是外部工作区资料；本机 skill 已复制到
   `~/.claude/skills/workisland-ui/references/`，仓库里保留本文件作为落地摘要。
