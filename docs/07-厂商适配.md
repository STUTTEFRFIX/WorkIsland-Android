# 厂商适配：vivo / 小米 / 红魔 能不能上岛

> 2026-10-26 调研。只写公开资料和本机实测；没有真机验证的一律标「未验证」。

## 7.1 结论速览

| 系统 | 上岛方式 | 状态 | 结论 |
|---|---|---|---|
| **ColorOS 16**（OPPO / 一加，Android 16） | 标准 Android 16 Live Updates | **本机实测通过** | 可用 |
| **HyperOS 3.0.300+**（小米 / 红米，Android 16+） | 系统自动把标准 Live Updates 包成「超级岛」 | 未实测（媒体与 HyperBridge 0.5.0 说明） | 理论可行，等真机 |
| **HyperOS 2 及更早** | 焦点通知 `miui.focus.param` + 小米白名单 | 需上架、软著、邮件申请、场景评审 | 不适用个人工具 |
| **vivo 国行 原子岛**（OriginOS 5 / 6） | `notification.superx.*` + vivo 白名单 | 需上架、软著、邮件申请、场景/UI 评审、定期巡查 | 不适配 |
| **红魔 OS 11 及更早** | 无岛 | — | 不适配 |
| **红魔 OS 12**（Android 17，AI 魔法岛） | 官方未说明是否接标准 API | 12 Pro+ 首发；旧机 2026-12 起分批 | 未验证 |
| 其他 Android 16 设备 | 标准 Live Updates | 取决于厂商实现 | 未验证 |

## 7.2 我们用的路线：标准 Android 16 Live Updates

- 通知用 `Notification.ProgressStyle` + `setRequestPromotedOngoing(true)`，系统侧标记是 `PROMOTED_ONGOING`。
- Google 在 I/O 2025 明确说 Live Updates 会下放给 Samsung、OnePlus、vivo、Xiaomi；具体到机型和系统版本由厂商决定。
- 代码位置：`Notifier.build()`；应用不依赖任何厂商 SDK，也没有私有字段。
- 系统不接时退回普通通知：功能不丢，只是不上岛。

## 7.3 厂商私有通道：字段能写，渲染要白名单

### 小米（焦点通知 / 超级岛）

- 客户端在 `Notification.extras` 里放 `miui.focus.param`、`miui.focus.pics`、`miui.focus.actions`。
- 系统会查焦点通知权限（`hasFocusPermission()`），没有白名单就不渲染。
- 申请：邮件 `mipush-permission@xiaomi.com`；要求应用上架、场景说明、产品方案、UI 稿；审核后联调、灰度（约 7–15 天全量）。

### vivo（原子通知 / 原子岛）

- 字段在 `notification.superx.*`：`template`、`infos`（左右信息区）、`shortInfos`（锁屏小卡）、胶囊字段等。
- 申请：邮件 `oosyztz@vivo.com`；要求先上架 vivo 应用商店、有软著，附场景说明、需求文档、UI 稿；7–10 个工作日审核 → 联合评审 → 联调 → 灰度；有定期巡查，不合格收回权限。
- 只面向高关注、有时间边界的场景（外卖、打车、导航、票务、录音、通话）；开发者工具类不在其中。

**共同点：** 字段不是权限。没有白名单，写进去也会被系统忽略。

## 7.4 Shizuku 旁路（实验，不默认开）

- Shizuku 给的是 **shell（uid 2000）**，不是 root：能跑 `am` / `cmd` / `content` / `settings`，改不了系统签名，也改不了厂商服务里的白名单。
- 可以试：用 shell 身份发一条带私有字段的通知，看厂商岛认不认 `com.android.shell` 这个包名（小米有社区先例 HyperBridge）。
- 做不到：给应用「授予」焦点通知 / 原子通知权限；改厂商白名单数据库。
- 代价：用户要装 Shizuku、开无线调试、重启后重新激活；ROM 更新容易失效；只能侧载分发。
- 结论：即使做，也只是设置里的实验开关，默认关闭，失败自动退回标准通知。

## 7.5 我们的策略

1. 主线只走标准 Live Updates，失败退回普通通知；
2. 不为没有真机验证的设备写厂商私有代码；
3. 代码里预留 `IslandAdapter` 扩展位，将来拿到权限或真机再加；
4. 文档只写验证过的结论，未验证的标「未验证」，不画饼。
