# 工作岛 · 提交说明

> **测试状态：Pre-release / Alpha**
> 仅在 **OnePlus PJA110 · ColorOS 16.0.3 · Android 16（SDK 36）· cccodroid 0.4.2** 上测试成功。
> 其他 ColorOS 版本与品牌机型未验证；项目仍在测试阶段，接口、文案和文件布局可能变动。

## 1. 项目一句话

把 cccodroid 里 Claude 的实时工作状态，显示在 ColorOS 16 的流体云 / 灵动岛上；干活时显示当前动作，完成时显示用时，8 秒后自动收起。

## 3. 验收步骤（3 分钟）

1. 安装 `apk/WorkIsland.apk`。
2. 打开「工作岛」，确认界面显示：
   - 通知：开
   - 实时更新：允许（有流体云 / 灵动岛的设备）
   - 电池：不优化
   - 显示方式：有岛设备开「系统流体云 / 灵动岛」；无岛设备开「悬浮胶囊」并授权悬浮窗
   - 大小与位置：在「悬浮胶囊大小与位置」里拖字号、高度、垂直位置、不透明度；上方预览实时变化
3. 在 cccodroid 里发一条消息，观察状态栏：
   - 有岛：干活时系统胶囊显示动作，结束时「任务完成」+ 用时，8 秒后收起；
   - 无岛：同样内容出现在半透明、触摸穿透的悬浮胶囊里，离开应用即可看到；
   - 结束后通知栏保留「工作岛 · 在后台等下一轮」。
4. 对照 `screenshots/` 中的四张状态图；悬浮胶囊的可调版与预览已编译，真机复测记录待补。

> 如果 cccodroid 是全新环境，需要先按 `docs/02-开发与部署.md` 第 4 节接入网关模块，并重启一次 cccodroid。

## 4. 设计要点（答辩/评审用）

1. **三层解耦**：网关（知道）→ driver（判断）→ 工作岛（画）。
2. **Android 16 Live Updates**：`ProgressStyle` + `POST_PROMOTED_NOTIFICATIONS` + `android.requestPromotedOngoing`，ColorOS 16 流体云直接接住，不需要 OPPO 私有白名单。
3. **对抗 OEM 冻结**：实测 ColorOS 会在后台把应用冻住（`do_freezer_trap`），所以定时器与事件流不放在应用里，放在活得比单轮任务更久的网关 driver 里。
4. **收工判定四道关**：看 `runs` 不看 `run`；`run_end` 后 2.5 秒复查；完成前 3 秒宽限；新轮次取消完成。解决了“还在干活就报完成”。
5. **视觉统一**：深色 `#1F1E1D`、陶土色 `#D97757`、鱼形图标，与 cccodroid 一致。
6. **无岛兜底**：应用自己画一条半透明、触摸穿透、按内容伸缩的悬浮胶囊；系统岛和悬浮胶囊各有一个开关，按设备选择。
7. **可调与预览**：字号 / 高度 / 垂直位置 / 不透明度四个滑块；设置页用同一个 `CapsuleView` 在模拟屏幕上实时预览，不需要先开悬浮窗权限。
8. **可回退**：对宿主的改动只有两行 + 一个新模块，原文件有备份；应用可独立卸载。

## 5. 已知限制（如实说明）

- cccodroid 被**强行停止**后，网关与 driver 都会消失，岛上可能停在最后一个状态；重开 cccodroid 恢复。
- ColorOS 的自启动、最近任务锁定需要用户手动开启；adb 白名单只能覆盖一部分。
- cccodroid 升级可能覆盖网关文件，需要重新接入（原文件已备份）。
- 工作岛的 Service 是 exported 的，同机应用可以伪造显示状态；生产化需加签名级权限。
- 系统岛外观由系统绘制，未使用 OPPO UPK 自定义卡片。
- 悬浮胶囊由本应用进程绘制，不接收触摸；ColorOS 冻结后台应用时动画会停在最后一帧，下一条状态更新唤醒。
- 悬浮胶囊的最终短版还没完成全机型复测；目前只在 OnePlus PJA110 上见过初版。
